# Reproducibility notes

## Scope

The repository reproduces the numerical validation reported in the associated manuscript:

1. Experiment I: D2Q9 finite-wavenumber transverse-shear validation.
2. Experiment II: D3Q19/D3Q27 CE2 population-vector validation.
3. Experiment III: weakly nonlinear Taylor–Green tangent-limit cross-check, including the manuscript time-history figure.
4. Experiment IV: curvature reconstruction on D3Q15, D3Q19 and D3Q27 from exact linearized BGK shear eigenmodes, the velocity-parity analysis, and reconstruction from fully evolved BGK populations.

It also archives the observability and constructive-reconstruction operators used by the theory.

## Required scientific inputs

Exact machine-readable normalized CE2 observability operators:

- `operators/Lhat_D3Q15.csv` (Experiment IV)
- `operators/Lhat_D3Q19.csv` (Experiments II–IV)
- `operators/Lhat_D3Q27.csv` (Experiments II–IV)

`Lhat_D3Q19.csv` and `Lhat_D3Q27.csv` must be the same files used in the symbolic analysis and Supplementary Material. `Lhat_D3Q15.csv` is generated by the archived exact procedure `scripts/generate_d3q15_operator.py`. That procedure also reproduces the D3Q19 and D3Q27 files exactly; it only reads them and never modifies them.

Exact curvature-reconstruction operators (generated from the files above by `src/curvature_reconstruction_exact.py`, serialized by `scripts/generate_reconstruction_operators.py`):

- `operators/reconstruction/observable_functionals.csv`
- `operators/reconstruction/D_D3Q15.csv`, `D_D3Q19.csv`, `D_D3Q27.csv`
- `operators/reconstruction/RH_D3Q15.csv`, `RH_D3Q19.csv`, `RH_D3Q27.csv`
- `operators/reconstruction/sensitivity_factors.csv`

The identities $R^H_Q\widehat L_Q=D_Q$ ($Q=15,19,27$) are checked in exact arithmetic from these files by `scripts/check_repository.py`, `scripts/generate_reconstruction_operators.py --check` and `tests/test_reconstruction_operator_files.py`.

## Production parameters

The production scripts are intentionally explicit rather than relying on CLI defaults.

### Experiment I

- grid: 256 x 256
- $\tau$: 0.9, 1.0, 1.1
- directions: [10], [21], [11]
- harmonics: 1,...,8
- perturbation amplitude: 1e-6
- time steps: 8

### Experiment II

- lattices: D3Q19, D3Q27
- $\tau$: 1.0
- perturbation amplitude: 1e-6
- directions: [100], [110], [111]
- N: 24, 32, 40, 48, 64, 80
- fundamental mode on each grid
- symmetry-distinct transverse polarizations retained

### Experiment III

- lattices: D3Q19, D3Q27
- N: 48
- $\tau$: 0.8
- $U_0$: 0.005, 0.01, 0.02
- equilibrium initialization
- startup discard: first 10 steps
- final nondimensional time: t* = 0.02
- spectral derivatives
- manuscript time-history figure: $U_0$ = 0.02, diagnostics at timesteps 10, 20, 30, 40, 48, $t^*=U_0t/N$

These Experiment III values encode the refined production protocol used in the current manuscript rather than the older generic defaults retained in the exploratory solver module. All amplitude-sweep table entries are evaluated at timestep 10.

### Experiment IV

- lattices: D3Q15, D3Q19, D3Q27; both shear branches
- $\tau$ = 1, $\rho_0$ = 1
- wavevector $\mathbf k=\frac{2\pi}{N}(1,2,3)$
- exact linearized eigenmodes and parity analysis: N = 24, 32, 40, 48, 64, 80, 96, 128
- fully evolved BGK: N = 24, 32, 48, 64, 80; $U_0=10^{-6}$ (primary); t = 0, 1, 2, 4, 8
- convergence exponents fitted for N ≥ 48

## Commands

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/check_repository.py --full

python scripts/reproduce_experiment_I.py
python scripts/reproduce_experiment_II.py
python scripts/reproduce_experiment_III.py
python scripts/reproduce_experiment_III_time_history.py
python scripts/reproduce_experiment_IV_linearized.py
python scripts/reproduce_experiment_IV_parity.py
python scripts/reproduce_experiment_IV_full_bgk.py
python scripts/plot_experiment_IV_paper_figures.py
```

The production calculations are independent and may be run separately. The Experiment IV publication figures depend only on the stored Experiment IV results.
