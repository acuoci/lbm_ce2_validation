# LBM CE2 population-observability: numerical validation

This repository contains the Python code used for the numerical validation in Section V of the associated theoretical manuscript on kinetic population observability in lattice Boltzmann methods (LBM).

The numerical calculations are deliberately small, transparent BGK collision-streaming implementations written in NumPy. They are intended to verify specific analytical predictions directly from time-evolved lattice populations, not to provide a general-purpose LBM solver.

## Numerical experiments

### Experiment I — D2Q9 finite-wavenumber shear response

`src/experiment_I_d2q9_shear.py` verifies the transverse-shear expansion

$$
\eta_K^{\mathrm{pop}} =
A(\theta,\tau)k
\left[1+B(\theta,\tau)k^2+O(k^4)\right].
$$

Here, $k = |𝐤|$ is the lattice wavenumber.

using exact discrete shear-eigenmode initialization followed by the full nonlinear D2Q9 BGK collision-streaming algorithm. The production sweep uses a 256 x 256 periodic lattice, three propagation families ([10], [21], [11]), three relaxation times, and eight harmonics per family.

Run:

```bash
python scripts/reproduce_experiment_I.py
```

Main outputs are written under `reference_results/experiment_I/`.

### Experiment II — D3Q19/D3Q27 CE2 population operator

`src/experiment_II_3D_shear.py` compares the complete measured kinetic population vector with

$$
g_Q^{\mathrm{CE2}}=C_0\widehat L_Q\mathbf q_F
$$

for exact three-dimensional transverse shear eigenmodes. The production calculation uses D3Q19 and D3Q27 at $\tau=1$, directions [100], [110], and [111], and N = 24, 32, 40, 48, 64, 80. Symmetry-distinct transverse polarizations are retained.

Run:

```bash
python scripts/reproduce_experiment_II.py
```

This experiment requires the exact symbolic operators `operators/Lhat_D3Q19.csv` and `operators/Lhat_D3Q27.csv`.

### Experiment III — weakly nonlinear Taylor-Green cross-check

`src/experiment_III_taylor_green.py` performs the non-modal Taylor-Green tangent-limit consistency check. The production driver deliberately overrides the older exploratory defaults in the solver and uses the final manuscript protocol:

- D3Q19 and D3Q27;
- N = 48;
- $\tau$ = 0.8;
- $U_0$ = 0.005, 0.01, 0.02;
- first 10 timesteps excluded from quantitative comparison;
- final nondimensional time t* = 0.02;
- spectral differentiation of the instantaneous velocity field.

Run:

```bash
python scripts/reproduce_experiment_III.py
```

This experiment also requires the two `Lhat` operator CSV files.

## Installation

Python 3.10 or newer is recommended. The numerical code depends only on NumPy and Matplotlib.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Before starting an expensive production run, check the repository inputs and Python syntax:

```bash
python scripts/check_repository.py
```

## Reproducing the manuscript calculations

Run each production script from the repository root. The scripts encode the parameters used for the current Section V and therefore provide the authoritative reproduction entry points. The command-line defaults inside the underlying experiment modules are retained mainly for inexpensive demonstrations and exploratory calculations; in particular, they should not be assumed to represent the final Taylor-Green production protocol.

The D2Q9 experiment is self-contained. Experiments II and III additionally require the exact machine-readable `Lhat_D3Q19.csv` and `Lhat_D3Q27.csv` operators generated by the theoretical symbolic analysis. Their population and curvature-coordinate ordering is part of the definition of the experiment.

See `REPRODUCIBILITY.md` for the complete parameter sets and release recommendations.
